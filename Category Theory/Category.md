## Morphism

For instance, in Set, a function is an isomorphism if and only if it is both injective and surjective, hence if and only if it is both a monomorphism and an epimorphism. 

Thus this property is a special feature of Set, and we should not expect it to hold automatically in every category; it will not hold in the category Ring of rings. It will hold in  
every abelian category (of which Set is not an example!).

Similarly, in Set a function is an epimorphism, that is, surjective, if and only if it has a right-inverse; this may fail in general, even in respectable categories such as the category Grp of groups.
